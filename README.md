# 格物造境 · 回响（gewuzaojing-echo）

Echo 是像素 RPG 宿主；QuillForge 是生成式世界编织引擎。索尔维会议是手工制作的高事实约束体验，VR 实验室中的“项目二”则通过游戏内 iframe 进入 QuillForge，生成、审阅世界书后开始 GALGAME。

## 快速开始

```powershell
pnpm setup
Copy-Item .env.example .env
pnpm dev
```

打开 `http://127.0.0.1:5000/`。QuillForge 独立页面位于 `http://127.0.0.1:8050/`。

## 验证

```powershell
pnpm test
```
