小游戏QUILLFORGE · 調査檔案

CASE FILE // MINIGAMES

选择一卷待查档案，系统将基于当前剧本素材实时生成小游戏内容（约 10~60 秒）。答题类每卷有 3 次作答机会，答错会揭示一条针对性线索。

言弹辩驳DEBATE

弹丸论破式飞屏击破：装填言弹、滚轮换弹，射穿论辩中呼啸而过的朱红「破绽」与蓝青「共鸣」。

线索指认EVIDENCE

从若干证物卡中，选出唯一能回答关键问题的线索。指认成立，推理即成立。

密码解密CIPHER

破译一段与剧情紧密相关的密文，加密规则就藏在提示里。

时间线排序TIMELINE

打乱的剧情片段散落一地，把它们按真实发生的先后顺序排列。

连线配对MATCH

调查板上散落着成对的信息，把左栏与右栏一一连线对应。

证物归类CLASSIFY

散落的证物条目需要按统一依据，投入正确的分类箱。

逐步解锁UNLOCK

一道多层机关，每一层当场验证，层层答对方能解锁封存档案。

巡航收集VOYAGE

驾驶巡逻艇限时航行，撞击打捞记忆浮标攒分达标，小心暗礁与游动水雷。

碎纸复原SHUFFLE

关键证物被撕成碎片，在调查台上两两交换，把它拼回一份完整的文件。

频段截听RADIO

旋转调频旋钮，让接收波形与目标密电波形重合，稳住片刻即可截获电文。

现场搜证SEARCH

限时勘查证物陈列架，圈出所有符合搜索目标的证物，一个不多一个不少。

密码转盘DIAL

拨动转盘密码锁试开，每次试拨都会得到 A/B 反馈，凭推理逼近真实密码。

档案室迷宫MAZE

赶在限时内穿过迂回曲折的迷宫抵达出口，方向键或触屏方向键移动。
